**Diskbox** replaces the Disk Viewer dashboard tile with a native-looking one: the array as a single card with its protection state, a parity row that turns amber during a parity check or rebuild and red when protection is lost or a disk is emulated, every data disk and pool with usage, temperature and SMART health, and a Needs attention list for full, hot or failing disks.

Settings: Settings, Utilities, Diskbox (or the gear icon on the tile).
