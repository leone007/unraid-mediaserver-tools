**Sysbox** replaces the System and Processor dashboard tiles with one native-looking tile: memory as a single bar (system, ZFS cache, Docker, free), boot, log and Docker vdisk usage, CPU load with history, temperature, power and per-thread heat map, the Intel GPU engines, wall power from a Shelly smart socket with the monthly kWh, network speed with the internet state and the busiest containers (details on the Network page), your router (any router with SSH, Asuswrt-Merlin and other Entware routers: CPU, memory, WAN speed and month, temperatures, Entware, AdGuard, Skynet, Tailscale and AiMesh, read through a key that can only run a small read script; Compact, Standard or Full), and a list of containers (busiest or selected) with start, stop, restart and log buttons. Anything that needs attention is listed at the top.

Settings: Settings, Utilities, Sysbox (or the gear icon on the tile).
