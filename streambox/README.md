**Streambox** puts Jellyfin on the Unraid dashboard as a native-looking tile: who is watching right now (direct play, direct stream or transcode, with progress and live TV guide data), GPU and CPU load with the current power draw, optional smart-socket wall power and monthly kWh, and the recently added titles. It can also announce new movies and seasons in Discord with Hungarian cards.

Settings: Settings, Utilities, Streambox (or the gear icon on the tile). A Jellyfin API key is required.
