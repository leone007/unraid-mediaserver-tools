**Seedbox** puts qBittorrent on the Unraid dashboard as a native-looking tile: the connection state (connected, firewalled or disconnected), torrents that need attention, and what is in transfer right now with speeds, ETA and progress bars, plus a link to the Web UI. Idle seeds are never listed, so the tile stays short even with hundreds of torrents.

Settings: Settings, Utilities, Seedbox (or the gear icon on the tile). The qBittorrent Web UI must be enabled.
